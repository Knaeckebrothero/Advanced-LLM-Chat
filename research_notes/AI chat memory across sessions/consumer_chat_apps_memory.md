# Long-term memory across sessions in consumer AI chat apps (other than Claude), as of 2026-11-01

Method note: research done 2026-11-01. openai.com and help.openai.com returned HTTP 403 to the fetch tool, so ChatGPT details come from press coverage and search-engine excerpts of OpenAI pages (marked). Google, Kimi and Doubao help pages were read directly. "Unofficial" marks reverse-engineering or third-party blogs.

## ChatGPT (OpenAI): saved memories, reference chat history, Dreaming, Projects, Temporary Chat

### Takeaway
ChatGPT has the most layered memory: (1) explicit "saved memories" (a user-visible notepad, injected every turn), (2) since April 2025, "reference chat history", which reverse-engineers found to be pre-computed summaries injected wholesale into the system prompt (no per-query RAG), and (3) since June 4, 2026, "Dreaming", a background process that synthesizes and revises memory from many conversations, with a user-facing "memory summary" page. Projects can isolate memory; Temporary Chat neither reads nor writes memory.

**Current controls (help center, via search excerpt)**
- Settings > Personalization has separate toggles; depending on the account's "memory experience" the options may be "Memory, Reference saved memories, Reference chat history, Memory summary, Manage, or Saved memories". Deleting a chat does not delete a saved memory created from it. The memory summary does not show everything: memory is "a continually updated synthesis of context from past chats, which may be broader than what can be shown as individual items". — [OpenAI Memory FAQ (403 to fetcher; via search excerpts)](https://help.openai.com/en/articles/8590148-memory-in-chatgpt); [ai-toolbox (secondary)](https://www.ai-toolbox.co/chatgpt-management-and-productivity/how-to-manage-chatgpt-memory-2026)
- Temporary Chat: not in history, does not use or create memory, not used for training, deleted after 30 days. Memory default on for Free/Plus/Pro/Team; off by default for Enterprise/Edu, admins can opt in or disable org-wide (secondary). — [Digital Applied](https://www.digitalapplied.com/blog/chatgpt-memory-dreaming-v3-openai-2026-guide)

**How it works technically (unofficial reverse engineering)**
- Simon Willison (2025-05-21) extracted the injected chat-history "dossier" with four sections: "Assistant Response Preferences", "Notable Past Conversation Topic Highlights", "Helpful User Insights", "User Interaction Metadata" (location, iOS app, conversation depth, model-usage percentages, activity counts). He objected that "The new memory feature removes that control completely" (could not see/edit it) and showed context leaking into unrelated tasks (a pelican image got a Half Moon Bay sign). — [Simon Willison](https://simonwillison.net/2025/May/21/chatgpt-new-memory/)
- Shlok Khemani (2025-09-08) describes four buckets sent with every message: "Interaction Metadata" (device, usage stats), "Recent Conversation Content" (timestamped list of ~40 recent chats, user messages only, updated each new chat), "Model Set Context" (the saved memories: short timestamped sentences, user-visible, take precedence in conflicts), and "User Knowledge Memories" (~10 AI-generated paragraphs, periodically regenerated, not visible in settings, mix stale facts with lasting preferences). "No vector databases. No knowledge graphs. No RAG." Method relies on asking ChatGPT, so partly self-reported. — [shloked.com](https://www.shloked.com/chatgpt-memory)
- Johann Rehberger documented the profile arriving in roughly six named sections (reported secondhand). — [Mohamed Yassin Substack](https://mohyassin.substack.com/p/chatgpts-hidden-memory-layer-the)
- Saved memories are written through a memory tool that the model invokes in a conversation, which is why untrusted content (a website, an image) can trigger writes via prompt injection (see SpAIware below). — [TechRadar on SpAIware](https://www.techradar.com/pro/hacker-creates-false-memories-in-chatgpt-to-steal-victim-data-but-it-might-not-be-as-bad-as-it-sounds); [TechSpot](https://www.techspot.com/news/104881-chatgpt-vulnerability-allows-hackers-record-sessions-indefinitely.html)
- Mem0 published "ChatGPT Started Dreaming: How Its Memory Actually Works" (not read; X article). — [mem0 on X](https://x.com/mem0ai/article/2071990201531118063)

### Inferences
- ChatGPT's architecture is "always-injected profile" rather than "search past chats on demand": saved memories + LLM-written summaries + recent-chat list, computed offline and prepended. Dreaming makes the summary layer the main one and adds revision of stale facts, which is the problem Khemani observed in 2025.
- The 2024 to 2026 arc moved writing from the user ("remember this") to the model (tool call) to a background job (dreaming), while visibility moved the other way (from hidden dossier back to a reviewable summary page) after criticism like Willison's.
- For a therapist persona, Project-only memory is the closest analogue: memory scoped to one context, isolated from the general profile.

### Gaps
- Could not read OpenAI's Dreaming post, Memory FAQ or release notes directly (403); the exact current Dreaming availability in the EU/EEA and on Free/Go as of 2026-11-01 is unconfirmed.
- No reverse-engineering of the post-Dreaming prompt format was read; whether the injected sections changed after June 2026 is unknown.
- The internal tool name for saved memories (commonly called "bio" in leaked system prompts) was not verified from a source in this session.
- OpenAI's handling of sensitive categories (health, mental health) in memory: OpenAI's original 2024 statement that it steers away from proactively remembering health details was not re-verified.

## Google Gemini: past chats ("Memory"), personal context, custom instructions / saved info, Personal Intelligence, Gems

### Takeaway
Gemini learns from past chats automatically (on by default since 2025-08-13 in launch countries, Europe only since ~2026-04-29), plus user-written instructions and, since January 2026, opt-in "Personal Intelligence" over Gmail/Photos/YouTube/Search. Memory is not used in Gems or Live; you delete memory by deleting chats. Google does not document the internal mechanism.

### Cited Findings
- 2025-08-13: setting under "Personal context" > "Your past chats with Gemini" lets Gemini "learn from your past conversations over time"; "This setting is on by default"; first on 2.5 Pro in select countries, 18+ consumer accounts only. Same post: Temporary Chats (not in recent chats or Activity, not used for personalization or training, kept "for up to 72 hours"); "Gemini Apps Activity" renamed "Keep Activity". — [Google blog](https://blog.google/products/gemini/temporary-chats-privacy-controls/)
- Personal context launched for free and paid users. — [Android Central](https://www.androidcentral.com/apps-software/ai/gemini-app-personal-context-uses-old-chats-future-personalized-answers-update)
- 2026-01-14: "Personal Intelligence" US beta: connects Gmail, Photos, YouTube, Search; off by default/opt-in; Gemini indicates which connected sources it used; personal accounts only. 2026-03-17 expanded to free US users across the Gemini app, AI Mode and Chrome; in that rollout "Memory" is the new name for "Past Gemini chats". — [Business Today](https://www.businesstoday.in/technology/news/story/google-pushes-gemini-deeper-into-users-lives-with-new-personal-intelligence-feature-511041-2026-01-15); [9to5Google](https://9to5google.com/2026/03/27/gemini-free-personal-intelligence-rollout/)
- 2026-03-26: "Import memory to Gemini": (a) a prompt pasted into ChatGPT/Claude that returns a user summary in five categories, "Demographics, Interests & Preferences, Relationships, Dated Events/Projects/Plans, and Instructions", no pronouns, verbatim preferences, dated evidence per entry; (b) ZIP chat-history import (up to 5 GB, 5 per day). Not available in the EEA, Switzerland or UK at launch. — [9to5Google](https://9to5google.com/2026/03/26/gemini-import/)
- 2026-04-29: memory and import reach France; memory "activé par défaut"; previously memory had been US-only since summer 2025 and "pas déployée en Europe"; managed at Settings > Contexte personnel > Mémoire. — [Blog du Modérateur](https://www.blogdumoderateur.com/gemini-fonctionnalite-memoire-import-chatgpt-disponibles-france/)
- Current help page: requires 18+, a personal Google Account (not work, school or supervised), and Keep Activity on; works in mobile, web, Chrome and watch; "Not available in Gems or Live chats" (you can ask in a text chat to reference a past Live conversation); to delete remembered info you delete the chats in Gemini Apps Activity ("may take a short time to stop influencing responses"); correct it by telling Gemini; ask "Did you use any info from past chats?". — [Google Help 16598469](https://support.google.com/gemini/answer/16598469)
- Personalization help hub lists past-chat memory, "custom instructions", Connected Apps, daily brief and a "Memory summary"; "These features are not available to everyone at this time." — [Google Help hub](https://support.google.com/gemini/answer/15637730)
- A vendor blog claims Gemini distills past chats into a profile rather than transcripts (vendor with a stake; unverified). — [MemoryLake](https://www.memorylake.ai/en/blogs/gemini-forgets-previous-conversations)
- At the Aug 2025 launch VentureBeat called Gemini's personalization "limited" and trailing OpenAI and Anthropic. — [VentureBeat](https://venturebeat.com/ai/google-adds-limited-chat-personalization-to-gemini-trails-anthropic-and-openai-in-memory-features)

### Inferences
- "Delete the chat to delete the memory" plus the "short time" lag suggests memory is derived from stored chats (summaries or an index rebuilt from Activity), not a separate user-editable store; this is inference, Google does not say.
- The five import categories are a plausible view of Google's internal memory schema (inference).
- Gems (Gemini's personas) are explicitly excluded from memory, i.e. Google chose not to give persona-scoped memory.

### Gaps
- Earlier milestones ("saved info", Nov 2024; recall of past chats for Advanced, Feb 2025) and whether "saved info" is now "custom instructions" were not verified in this session.
- No technical documentation (RAG over chats vs injected profile) found.
- Current EEA/UK status beyond France not verified.

## Kimi (Moonshot AI) and DeepSeek

### Takeaway
Kimi has cross-session memory, and a new version is rolling out from October 2026: automatic and explicit memories in a "Memory Space", plus referencing past chats, with a citation indicator, export/import, and a refusal to store sensitive data including suicide/self-harm information. DeepSeek's consumer app has no cross-session memory as of 2026-11-01 (no official feature found; open user feature requests as recent as 2026-10-08).

### Cited Findings
**Kimi (official help center, read 2026-11-01)**
- "The new memory experience is rolling out gradually from October 2026"; accounts still showing "Memory Instructions" may not have it yet. — [Kimi Help: Memory and Memory Space](https://www.kimi.ai/help/features/memory-space)
- Two sources: "Memory Space" (saved information in files Kimi can consult) and "past chats"; used "only when it is relevant"; a citation indicator at the end of a reply shows which sources were used. — [Kimi Help](https://www.kimi.ai/help/features/memory-space)
- Writing: automatic ("Kimi can remember details from your conversations", e.g. preferred name, professional background, response preferences) and explicit ("Remember that I like Radiohead"); after you start a new chat "the system organizes information from past conversations into Memory Space. Updates can take time." — [Kimi Help](https://www.kimi.ai/help/features/memory-space); [Kimi Help: Memory tips](https://www.kimi.com/en/help/features/memory-tips)
- Separate "Chat settings" (Preferred name, Occupation, "Instructions for Kimi") for standing instructions; project requirements go in project instructions; memory availability in project chats and scheduled tasks differs from regular chats. — [Kimi Help](https://www.kimi.ai/help/features/memory-space)
- Controls: Settings > Personalization > Chat memory (kimi.ai/settings/memory); off = no use and no new memories; turning off does not delete existing memories; delete single memories or clear the space; corrections by telling Kimi ("Correction: I now work in London"); deleting memory does not delete chats and vice versa; import from other AI services and export supported. — [Kimi Help](https://www.kimi.ai/help/features/memory-space)
- Refuses to store as memory: identity document numbers, bank card numbers, criminal or victimization records, "information about suicide or self-harm", about you or others. — [Kimi Help](https://www.kimi.ai/help/features/memory-space)
- A third-party test (Aug 2026) says Kimi states saved memory is not used for training (unverified). — [ki-ai.chat](https://ki-ai.chat/guides/kimi-memory/)
- Kimi's original "无损记忆" (lossless memory) marketing referred to long context (200k Chinese characters), not personal memory. — [Baidu Baike](https://baike.baidu.com/item/%E6%9C%88%E4%B9%8B%E6%9A%97%E9%9D%A2Kimi/68612029)
- Moonshot's API platform separately offers a "Memory" tool for developers (persisting history and preferences). — [Kimi API Platform](https://platform.moonshot.ai/)

**DeepSeek**
- No official DeepSeek announcement or help page describing cross-chat memory found; third-party guides say the app has no memory setting, no saved memories, no custom instructions field. — [deepseek.com.pk](https://deepseek.com.pk/does-deepseek-have-memory-feature/); [MemoryPlugin (vendor)](https://blog.memoryplugin.com/does-deepseek-have-memory/)

### Inferences
- Kimi's design (memory as files the model "consults", relevance-gated use, citations, "organized after you start a new chat") reads like agentic retrieval over a memory store plus past-chat search, i.e. closer to on-demand lookup than ChatGPT's always-injected dossier. Inference from help-page wording; Moonshot does not publish the mechanism.
- Kimi's exclusion of suicide/self-harm content from memory is a directly relevant precedent for a therapist persona: a mainstream product chose not to persist exactly the data such a persona would most want to recall.
- For an app serving DeepSeek models, memory has to be built by the app; the model vendor's app offers no pattern to copy.

### Gaps
- Kimi's pre-October-2026 memory ("Memory Instructions") launch date and behaviour not found from an official source; capacity limits and incognito mode not documented.

## Common patterns across products

### Takeaway
Two write paths (explicit "remember X" applied immediately; automatic extraction by a background job) and two read paths (always-injected profile/summary vs relevance-gated lookup of memories and past chats) recur everywhere. Nearly all offer a toggle, a view/delete list, a temporary/incognito chat, and decouple deleting chats from deleting memories.

### Cited Findings
- Always-injected, no RAG: ChatGPT (reverse-engineered). — [shloked.com](https://www.shloked.com/chatgpt-memory)
- Relevance-gated with citations: Kimi ("only when it is relevant", citation indicator); Gemini answers "Did you use any info from past chats?" and Personal Intelligence names its connected sources. — [Kimi Help](https://www.kimi.ai/help/features/memory-space); [Google Help](https://support.google.com/gemini/answer/16598469); [Business Today](https://www.businesstoday.in/technology/news/story/google-pushes-gemini-deeper-into-users-lives-with-new-personal-intelligence-feature-511041-2026-01-15)
- Background batch synthesis: ChatGPT Dreaming; Doubao scheduled refresh; Kimi organizes memory after a new chat starts. — [AI Catchup](https://aicatchup.com/news/chatgpt-dreaming-memory-architecture); [Doubao FAQ](https://www.doubao.com/legal/memory_faq); [Kimi Help](https://www.kimi.ai/help/features/memory-space)
- Deleting a chat does not delete memories derived from it (ChatGPT, Kimi, Doubao), except Gemini, where you delete chats to delete memory. — [OpenAI FAQ excerpt](https://help.openai.com/en/articles/8590148-memory-in-chatgpt); [Kimi Help](https://www.kimi.ai/help/features/memory-space); [Doubao FAQ](https://www.doubao.com/legal/memory_faq); [Google Help](https://support.google.com/gemini/answer/16598469)
- Incognito modes: ChatGPT Temporary Chat (no memory read/write, 30-day deletion); Gemini Temporary Chats (72 h). — [Digital Applied](https://www.digitalapplied.com/blog/chatgpt-memory-dreaming-v3-openai-2026-guide); [Google blog](https://blog.google/products/gemini/temporary-chats-privacy-controls/)
- Scoping: ChatGPT project-only memory; Kimi projects differ; Gemini excludes Gems and Live; Meta excludes group chats. — [Simon Willison](https://simonwillison.net/2025/May/21/chatgpt-new-memory/); [Kimi Help](https://www.kimi.ai/help/features/memory-space); [Google Help](https://support.google.com/gemini/answer/16598469); [Silicon Republic](https://www.siliconrepublic.com/machines/meta-ai-memory)
- Separate "standing instructions" from learned memory: Kimi Chat settings, Gemini custom instructions, ChatGPT custom instructions vs memory. — [Kimi Help: Memory tips](https://www.kimi.com/en/help/features/memory-tips); [Google Help hub](https://support.google.com/gemini/answer/15637730)
- Portability: Gemini (2026-03-26) and Kimi (Oct 2026) import memories from other assistants; Gemini's import uses a prompt that makes the other assistant dump its profile. — [9to5Google](https://9to5google.com/2026/03/26/gemini-import/); [Kimi Help](https://www.kimi.ai/help/features/memory-space)

### Inferences
- Defaults split: automatic memory on by default (ChatGPT, Gemini) vs opt-in (Le Chat, Gemini Personal Intelligence). In the EEA, ChatGPT's chat-history reference was opt-in. For a self-hosted EU app, opt-in per persona is the conservative choice.
- Products converge on a user-visible, editable summary even when the real store is broader (OpenAI admits its summary "may be broader than what can be shown").

## Reported problems: privacy, regulators, sycophancy and "AI psychosis", leakage, stale memories

### Takeaway
No regulator action targeting memory specifically was found; the visible regulatory effect is vendors withholding memory in the EEA/UK. Documented problems are research findings (most memories created without explicit request, a large share psychological or personal data), prompt-injection memory poisoning, context leaking into unrelated tasks, stale facts, and lawsuits and clinical reports linking memory to harmful dependency.

### Inferences
- For the therapist persona: memory is exactly the feature critics link to dependency and delusion reinforcement, and mental-health data is GDPR special-category data. Mitigations seen in products: explicit opt-in, scoped memory (per persona/project), user-visible and editable records, citations when memory is used, exclusion or special handling of self-harm content, a temporary mode, and treating tool-written memories as an injection surface (untrusted content must not write memory).
